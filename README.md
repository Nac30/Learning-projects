# Learning Projects

This repository contains my **frontend development practice projects** built with **HTML5, CSS3, and JavaScript**.
Each project focuses on improving my skills in **DOM manipulation, responsive design, and interactive UI development**.

---

## 📂 Projects

### 1. [Mapty – Workout Tracking Map Application](./Mapty)

A map-based workout tracking application that allows users to log running and cycling workouts by interacting with a live map.

* **Tech Stack:** HTML5, CSS3, JavaScript (ES6+), Leaflet.js
* **Features:**

  * Geolocation-based map rendering
  * Click-to-add workouts directly on the map
  * Object-Oriented Programming with classes and inheritance
  * Dynamic form rendering based on workout type
  * Persistent data storage using `localStorage`
  * Interactive markers and popups for each workout

👉 *Live Demo: [https://nac30.github.io/Learning-projects/Mapty/](https://nac30.github.io/Learning-projects/Mapty/)*

### 2. [NacTube – YouTube-Inspired Video Gallery](./NacTube)

A YouTube-style video gallery clone with dynamic search and category-based filtering.

* **Tech Stack:** HTML5, CSS3 (Flexbox, Grid, Responsive Design), JavaScript
* **Features:**

  * Real-time search by video title/uploader
  * Category-based filtering with active states
  * Responsive grid layout with hover animations
  * "No results" fallback message

👉 *Live Demo: [https://nac30.github.io/Learning-projects/NacTube/](https://nac30.github.io/Learning-projects/NacTube/)*

### 3. [Pig Game – Interactive Dice Game](./Pig-Game)

A two-player dice game where players roll, hold, and race to reach the target score.

* **Tech Stack:** JavaScript, HTML5, CSS3
* **Features:**

  * Roll, Hold, and Reset mechanics
  * State management with DOM updates
  * Win condition logic with player switching

👉 *Live Demo: [https://nac30.github.io/Learning-projects/Pig-Game/](https://nac30.github.io/Learning-projects/Pig-Game/)*

## 🚀 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Nac30/Learning-projects.git
   ```
2. Navigate into the project folder you want to run, for example:

   ```bash
   cd Learning-projects/Mapty
   ```
3. Open `index.html` in your browser.
